# AI-Powered Food Allergen Detection and Ingredient Risk Assistant Using NLP and OCR

**Student:** Rahimi Mohammad Mirwais
**Folder:** rah086
**Course:** Professional Training (YN3012170034)

## Project Description
This application reads the ingredient label of a food product from an image (OCR),
detects allergens in the text (NLP), and shows a risk report based on the
allergies selected by the user.

## Planned Features
- Upload a photo of an ingredient label
- Extract text using OCR
- Detect allergens and ingredients using NLP
- Risk level report (Low / Medium / High) for the user's allergies
- Interactive interface built with Gradio
